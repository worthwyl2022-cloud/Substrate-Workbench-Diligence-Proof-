# Contract Alignment

This repository is the **diligence and review workbench**. It records evidence and runs local review tooling; it does not issue authority or create canonical receipts.

The sole authority source is [`cranium-kernel`](https://github.com/worthwyl2022-cloud/cranium-kernel). Workbench records must link to a source commit, exact command, real output, and limitation. Frozen corpus expectations are test inputs; they are not proof until the real Kernel mechanism runs. Generated timestamps, random digests, static proof packs, UI PASS labels, and local state are not receipts or verification.

The workbench must fail closed in its language: unverified, unavailable, or fixture data is labeled accordingly and is never promoted to an acquisition claim.
