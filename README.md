# Substrate Workbench — Diligence Proof

## Purpose

This repository is the diligence and review workbench for the Cranium portfolio. It collects acquisition-oriented proofs, verification records, navigation, and review artifacts without becoming an alternate authority engine.

## Portfolio navigation

- **Canonical authority boundary:** [cranium-kernel](https://github.com/worthwyl2022-cloud/cranium-kernel)
- **Application and cognitive layer:** [Cranium-Core-](https://github.com/worthwyl2022-cloud/Cranium-Core-)
- **Conceptual/reference substrate:** [Cranium-Substrate-](https://github.com/worthwyl2022-cloud/Cranium-Substrate-)

## Operating boundary

The workbench records and explains diligence evidence. It does not grant authority, mutate canonical kernel state, or replace repository-native tests. Claims should link to executable tests, immutable receipts, source locations, or clearly labeled review notes.

## Review conventions

When adding an artifact, identify its source repository, commit or version context, execution command, result, and any residual limitation. Keep generated evidence separate from production source and do not present deterministic attack vectors as external production evidence.
